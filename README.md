### Beam for Linux

Use your Mac from a Linux desktop (x86_64 Wayland: Omarchy, Hyprland, and friends). Install into `~/.local`:

```sh
curl -fsSL https://github.com/Aayush9029/beam-issues/releases/latest/download/install-linux.sh | sh
```

Then open **Beam** from your launcher, pick your Mac, and approve the code shown on the Mac. Needs FFmpeg, VA-API (Mesa), and a Wayland compositor; on Arch/Omarchy: `sudo pacman -S --needed ffmpeg libva-mesa-driver`.

| Keys | Action |
|---|---|
| Ctrl+Alt+Esc | Give Super shortcuts back to your desktop / take them again |
| Ctrl+Alt+1..5 | Window size presets |
| Ctrl+Alt+F | Fullscreen |
| Ctrl+Alt+S | Stats |
| Ctrl+Alt+Q | Disconnect |
