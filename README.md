### Beam for Linux

```sh
curl -fsSL https://github.com/Aayush9029/beam-issues/releases/latest/download/install-linux.sh | sh
```

Open **Beam**, pick your Mac, and approve the code on the Mac. Needs FFmpeg and VA-API on Wayland (x86_64). Press **Ctrl+Alt+Q** to quit.
